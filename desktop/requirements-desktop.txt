# Dependencies for the portable Windows desktop build.
#
# Trimmed from the root requirements.txt: excludes gunicorn (Unix-only,
# relies on fcntl/fork, cannot run on Windows), psycopg2-binary, redis and
# django-redis (all Postgres/Redis-only — the desktop build always runs on
# a local SQLite file, never a shared cache). Adds the desktop-only runtime
# (waitress as the embedded WSGI server, pywebview for the native window,
# pyinstaller to freeze it all into one folder).
#
# Versions for packages also used by the server deployment are pinned to
# match requirements.txt exactly. pywebview / pyinstaller / pyinstaller-hooks-contrib
# have no server-side equivalent to match, so they're pinned to the latest
# available version as of this writing — bump deliberately, don't let CI
# silently float to a new major version.
